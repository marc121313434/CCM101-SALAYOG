Mission Overview
This mission focused on exploring cloud computing fundamentals through hands‑on Linux investigation and cloud provider research. It guided the process of identifying infrastructure components, comparing major platforms, and designing a simple cloud architecture.

---

Objectives
- Investigate a Linux environment using terminal commands.  
- Identify compute, storage, networking, and OS components.  
- Research AWS, Azure, and GCP core services.  
- Design a basic cloud infrastructure diagram.  
- Document findings and reflections in Markdown format.  

---

Cloud Infrastructure Components
- **Compute Resource:** CPU cores and virtual machine instance.  
- **Storage Resource:** Disk capacity and mounted file systems.  
- **Networking Resource:** IP address and hostname configuration.  
- **Operating System:** Ubuntu 20.04 LTS kernel managing all resources.  

---

Tools Used
- **KillerCoda Playground** – Linux environment for investigation  
- **GitHub Repository** – Documentation and portfolio storage  
- **Markdown Editor** – Formatting technical reports  
- **Diagramming Tool** – (Draw.io / PowerPoint) for cloud architecture design  

---

Linux Commands Executed

cat /etc/os-release      # Identify operating system
uname -r                 # Check kernel version
lscpu                    # View CPU details
nproc                    # Count CPU cores
free -h                  # Display memory usage
df -h                    # Show disk space
lsblk                    # List block devices
hostname                 # Display hostname
ip addr show             # View IP address
```
