AWS:

- Amazon EC2 (Elastic Compute Cloud) for virtual machines
- Amazon EBS (Elastic Block Store) for disk storage
- Amazon CloudWatch for monitoring

Microsoft Azure:

- Azure Virtual Machines for compute
- Azure Managed Disks for storage
- Azure Monitor for performance tracking

Google Cloud Platform (GCP):

- Google Compute Engine for virtual machines
- Persistent Disk for storage
- Cloud Monitoring for system metrics
