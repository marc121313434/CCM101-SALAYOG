Checkpoint 4 – Cloud Platform Recommendation Challenge

Client A – Startup Company
Recommended Platform: Google Cloud Platform (GCP)  
Reasoning: GCP is ideal for startups because of its competitive pricing, sustained-use discounts, and strong scalability features. It provides powerful developer tools and managed services that allow rapid deployment without heavy upfront costs. Its AI/ML capabilities also support future innovation as the company grows.
Suggested Services:

- Google Compute Engine (VMs)
- Firebase (mobile app backend)
- Google Cloud Storage (scalable storage)

Client B – University
Recommended Platform: Microsoft Azure  
Reasoning: Since the university already uses Windows Server, Microsoft 365, and Active Directory, Azure offers seamless integration. Azure Active Directory extends identity management to the cloud, while hybrid solutions make migration smooth. This reduces complexity and ensures compatibility with existing Microsoft technologies.
Suggested Services:

- Azure Virtual Machines
- Azure Active Directory
- Azure SQL Database

Client C – AI Research Company
Recommended Platform: Google Cloud Platform (GCP)  
Reasoning: GCP is the strongest in AI and ML, with TensorFlow, Vertex AI, and BigQuery. It provides high-performance computing resources and specialized hardware like TPUs (Tensor Processing Units) for training complex models. This makes it the best choice for research-intensive workloads.
Suggested Services:

- Google Kubernetes Engine (GKE)
- Vertex AI (ML development)
- Tensor Processing Units (TPUs)

Client D – Global E-Commerce Company
Recommended Platform: Amazon Web Services (AWS)  
Reasoning: AWS offers the most extensive global infrastructure, ensuring high availability and low latency for customers worldwide. Its auto-scaling, content delivery, and security services make it ideal for large-scale e-commerce operations. AWS’s breadth of services supports everything from payment processing to analytics.
Suggested Services:

- Amazon EC2 (compute)
- Amazon S3 (storage)
- Amazon CloudFront (content delivery)

Checkpoint 6 – Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
| --- | --- | --- |
| **Startup Company** | Google Cloud Platform (GCP) | GCP offers competitive pricing, sustained-use discounts, and developer-friendly tools like Firebase. It allows startups to scale quickly while keeping costs low, making it ideal for rapid growth. |
| **Enterprise Organization** | Amazon Web Services (AWS) | AWS provides the broadest range of services and the largest global infrastructure. Enterprises benefit from its scalability, reliability, and wide ecosystem of enterprise-ready solutions. |
| **Microsoft Environment** | Microsoft Azure | Azure integrates seamlessly with Windows Server, Microsoft 365, and Active Directory. It is the natural fit for organizations already invested in Microsoft technologies. |
| **AI / Machine Learning** | Google Cloud Platform (GCP) | GCP leads in AI/ML with TensorFlow, Vertex AI, and TPUs. It provides advanced tools and infrastructure for training and deploying machine learning models. |
| **Kubernetes Deployment** | Google Cloud Platform (GCP) | GCP pioneered Kubernetes and offers Google Kubernetes Engine (GKE), the most mature and feature-rich managed Kubernetes service. |
| **Global Web Application** | Amazon Web Services (AWS) | AWS’s global reach, auto-scaling, and services like CloudFront make it ideal for multinational e-commerce and web applications requiring high availability and low latency. |
