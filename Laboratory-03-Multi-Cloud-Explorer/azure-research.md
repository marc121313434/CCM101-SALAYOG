*Brief Overview

Microsoft Azure ay inilunsad noong 2010 at nagbibigay ng integrated cloud services para sa compute, storage, AI, networking, at hybrid cloud.

*Global Infrastructure

- 80+ Regions at 500+ datacenters
- May 190+ points-of-presence at 165,000 miles fiber optic cables

*Cloud Management Console

Ang Azure Portal ay unified interface para sa resource management, monitoring, at deployment.

*Four Core Services

- Azure Virtual Machines – compute
- Azure Blob Storage – scalable storage
- Azure SQL Database – managed database
- Azure Kubernetes Service (AKS) – container orchestration

*Three Advantages

- Deep integration sa Microsoft ecosystem
- Malakas na hybrid cloud capabilities
- Malawak na compliance certifications

*Typical Enterprise Use Cases

- Enterprise workloads (SQL Server, SAP)
- Hybrid cloud deployments
- AI-powered analytics at apps
