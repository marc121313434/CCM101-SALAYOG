  Brief Overview

Amazon Web Services (AWS) ay inilunsad noong 2006 at ngayon ay ang pinakamalawak na cloud platform na may higit sa 200+ services para sa compute, storage, AI, at networking.

  Global Infrastructure

- 39 Regions at 124 Availability Zones
- May 750+ Local Zones at 33 Wavelength Zones para sa low-latency apps
- Backbone network na may 20M km fiber optic cabling

  Cloud Management Console

- Ang AWS Management Console ay web-based interface para sa EC2, S3, Lambda

  Four Core Services
- Amazon EC2 – virtual servers
- Amazon S3 – scalable object storage
- Amazon RDS – managed relational databases
- AWS Lambda – serverless compute

  Three Advantages

- Pinakamalawak na global coverage
- Malawak na ecosystem ng services at AI tools
- Malakas na security at compliance

  Typical Enterprise Use Cases

- Hosting ng SAP/Oracle workloads
- Big data analytics at AI training
- Global e-commerce at content delivery
