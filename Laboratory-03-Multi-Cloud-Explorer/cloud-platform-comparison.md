1. Which cloud provider offers the broadest range of services?  
- AWS offers the broadest range of services, with over 200 fully featured offerings across compute, storage, AI, IoT, and networking. Its global infrastructure is unmatched, making it ideal for enterprises that need scale and diversity.

2. Which provider best integrates with Microsoft technologies?  
- Microsoft Azure is the best choice for organizations heavily invested in Microsoft technologies. It integrates seamlessly with Windows Server, SQL Server, Office 365, and Active Directory, making hybrid cloud deployments straightforward.

3. Which provider is strongest in Artificial Intelligence and Kubernetes?  
- Google Cloud Platform leads in AI and Kubernetes. With TensorFlow, BigQuery, and Google Kubernetes Engine (GKE), it provides cutting-edge tools for machine learning, analytics, and container orchestration.

4. Which cloud platform would you personally choose and why?  
- I would personally choose Google Cloud Platform because of its strong focus on AI/ML and Kubernetes, which are critical for modern application development and data-driven innovation. Its competitive pricing and advanced analytics tools make it especially appealing for startups and research projects.
